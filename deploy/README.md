# Как запустить сайт LWL на своей Linux-машине

Сайт — это одна программа на Node.js (`server/`) и одна база SQLite (файл `/var/lib/lwl/lwl.db`).
Перед ней стоит nginx: он раздаёт сайт по HTTPS на вашем домене. Всё ставится одной командой,
а сайт сам запускается при включении машины и перезапускается, если упал.

## 1. Что нужно

- Машина с **Ubuntu 22.04/24.04** или **Debian 12** (VPS или домашний компьютер) и доступ по SSH с `sudo`.
- **Белый (публичный) IP.** На VPS он есть всегда. Дома — уточните у провайдера («белый/статический IP»)
  и пробросьте порты на роутере: **80** и **443** (сайт), **25565** (Minecraft) → на эту машину.
- **Домен** (например, на reg.ru).

## 2. Домен на reg.ru

1. Купите домен: reg.ru → «Домены».
2. Откройте «Мои домены» → ваш домен → «DNS-серверы и управление зоной». DNS-серверы оставьте
   от reg.ru (`ns1.reg.ru`, `ns2.reg.ru`).
3. В «Управлении зоной» добавьте записи:
   - **A**, имя `@`, значение — IP машины;
   - **A**, имя `www`, значение — тот же IP.
4. Подождите: обычно 15–60 минут, иногда до суток. Проверка на машине: `getent hosts ваш-домен.ru` —
   должен показать ваш IP.

Хотите, чтобы игроки заходили по домену (например, `play.ваш-домен.ru`)? Добавьте ещё одну
**A**-запись с именем `play` на тот же IP (если Minecraft на этой же машине) и впишите этот адрес
в кабинете: «Сервер» → «Адрес сервера».

## 3. Установка (5 минут)

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/pay4ilo/claude-top.git lwl
cd lwl
sudo ./deploy/install.sh ваш-домен.ru ваша@почта.ru
```

Если репозиторий приватный, `git clone` спросит логин и **токен** GitHub вместо пароля
(GitHub → Settings → Developer settings → Personal access tokens). Можно и просто скачать
архив кода с GitHub, распаковать на машине и запустить `install.sh` из этой папки.

Установщик:

- ставит Node.js 24, nginx и certbot;
- создаёт системного пользователя `lwl` и папки:
  - `/opt/lwl` — код,
  - `/var/lib/lwl` — база и сборки,
  - `/etc/lwl/lwl.env` — настройки,
  - `/var/backups/lwl` — бэкапы;
- включает службу **`lwl`**: автозапуск при загрузке и перезапуск через 3 секунды после падения;
- включает ежедневный бэкап базы (04:30, хранится 14 дней);
- настраивает nginx и HTTPS-сертификат Let's Encrypt (продлевается сам).

Если на момент установки DNS ещё не обновился, сертификат не выдастся — установщик так и скажет.
Когда `getent hosts ваш-домен.ru` покажет ваш IP, выполните:
`sudo certbot --nginx -d ваш-домен.ru -d www.ваш-домен.ru --redirect`.

## 4. Стать админом

Почта, которую вы указали при установке, записана в `LWL_ADMINS` в `/etc/lwl/lwl.env`.
Откройте сайт и **зарегистрируйтесь с этой почтой** — аккаунт сразу станет админом («Админ» под ником).
Такого админа нельзя случайно понизить из админки.

Дальше всё настраивается в кабинете:

- **«Сервер»** — адрес сервера, версия, подсказка для игроков, ссылки на Telegram и Discord, сборки
  (кнопка «Добавить сборку», потом «Загрузить файл», потом «Опубликовать»);
- **«Люди»** — роли и ссылки для сброса пароля;
- **«Заявки»** — при одобрении человек становится «Игроком», и у него открывается вкладка «Сервер».

## 5. Как это работает после установки

| Что | Команда |
|-----|---------|
| Состояние сайта | `systemctl status lwl` |
| Логи в реальном времени | `journalctl -u lwl -f` |
| Перезапустить | `sudo systemctl restart lwl` |
| Список аккаунтов | `sudo lwl-cli users` |
| Сделать админом | `sudo lwl-cli role НИК admin` |
| Ссылка для сброса пароля | `sudo lwl-cli reset-link НИК` |
| Бэкап вручную | `sudo systemctl start lwl-backup` (файл появится в `/var/backups/lwl`) |

Проверка автозапуска: `sudo reboot`, через минуту сайт снова открывается.

## 6. Обновление сайта

```bash
cd ~/lwl
git pull
sudo ./deploy/update.sh
```

Перед обновлением делается бэкап базы. Если в новой версии менялась база, она обновится сама при запуске.

## 7. Восстановление из бэкапа

```bash
sudo systemctl stop lwl
sudo cp /var/backups/lwl/lwl-2026-09-30.db /var/lib/lwl/lwl.db
sudo rm -f /var/lib/lwl/lwl.db-wal /var/lib/lwl/lwl.db-shm
sudo chown lwl:lwl /var/lib/lwl/lwl.db
sudo systemctl start lwl
```

Бэкап — это только база: аккаунты, заявки, переписка, настройки и аватары. Файлы сборок лежат
в `/var/lib/lwl/packs/`. Если нужно, копируйте их отдельно или просто загрузите заново.
Для надёжности время от времени скачивайте `/var/backups/lwl` на другой компьютер.

## 8. Настройки (`/etc/lwl/lwl.env`)

| Переменная | Что это |
|------------|---------|
| `LWL_PUBLIC_URL` | Адрес сайта с `https://` — из него собираются ссылки сброса пароля |
| `LWL_ADMINS` | Почты или ники владельцев через запятую — всегда админы |
| `LWL_DATA_DIR` | Папка с базой и сборками (`/var/lib/lwl`) |
| `LWL_PORT`, `LWL_HOST` | Где сайт слушает (`127.0.0.1:8080`, наружу его отдаёт nginx) |
| `LWL_TRUST_PROXY` | `1` — брать IP посетителя из заголовка nginx (для защиты от перебора паролей) |
| `LWL_MAX_UPLOAD_MB` | Максимальный размер сборки (по умолчанию 2048 МБ; в nginx стоит лимит 2100 МБ) |

После правки: `sudo systemctl restart lwl`.

## 9. Minecraft-сервер на этой же машине (необязательно)

Чтобы сервер тоже поднимался сам после перезагрузки, возьмите шаблон `deploy/minecraft.service.example`:
поправьте в нём папку, имя jar-файла и память и следуйте инструкции в начале файла. Не забудьте порт
25565 (`sudo ufw allow 25565/tcp`, если включён ufw, и проброс на роутере, если машина дома).
Моды для сервера и команда вайтлиста — в `minecraft/README.md`.

## 10. Если что-то не так

- **502 Bad Gateway** — сайт не запущен: `systemctl status lwl`, `journalctl -u lwl -n 50`.
- **Сайт открывается только по http** — не выдан сертификат (см. пункт 3).
- **Не загружается большая сборка** — проверьте `LWL_MAX_UPLOAD_MB` и свободное место (`df -h /var/lib/lwl`).
- **У всех одинаковый IP в логах / блокировки срабатывают на всех сразу** — в `lwl.env` должно быть `LWL_TRUST_PROXY=1`.
- **Забыли пароль админа** — `sudo lwl-cli reset-link ВАШ_НИК` и откройте выданную ссылку.
