# Карточки игроков для Figma

SVG со слоями, снятые с настоящей вёрстки сайта (`npm run figma:cards`, игроки выдуманные).
Тексты — текстовые слои (Russo One, Inter — есть в Figma), фоны — градиенты и фигуры, скины — картинки.

**Как открыть:** перетащите `lwl-cards.svg` в любой файл Figma (или откройте SVG в блокноте,
скопируйте всё и вставьте в Figma через Ctrl+V). Отдельные `NN-*.svg` можно перетащить пачкой —
каждый станет своим фреймом.

**Как вернуть правки:** выделите фрейм → правый клик → *Copy/Paste as → Copy as SVG* и вставьте
в чат/задачу, или *Export → PNG*, или пришлите ссылку на файл с доступом на просмотр.

Пересобрать после изменений вёрстки: `npm run figma:cards`
(если Chromium от Playwright не установлен — `node tools/figma-cards.mjs --channel msedge`).
