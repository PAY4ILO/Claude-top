# Моды для сервера LWL (Fabric, Minecraft 26.3)

Два серверных мода. Игрокам ничего ставить не нужно: оба работают только на сервере
и подходят для сервера с `online-mode=false`.

| Мод | Что делает |
|-----|-----------|
| **LWL Skins** (`lwl-skins-1.0.0.jar`) | Скины как в SkinsRestorer: по нику лицензии или из PNG по ссылке. Видны всем, меняются без перезахода. |
| **LWL Auth** (`lwl-auth-1.0.0.jar`) | Защита ников. Игрок с лицензией заходит сразу, остальные — по паролю (`/register`, `/login`). |

Моды независимы: можно поставить один или оба.

## Установка

1. На сервере должны стоять Fabric Loader 0.19.5+, **Fabric API** и Java 25.
2. Скопируйте `lwl-skins-1.0.0.jar` и/или `lwl-auth-1.0.0.jar` в папку `mods/` сервера.
3. Запустите сервер. Файлы настроек появятся сами:
   `config/lwl-skins.json`, `config/lwl-auth.json`.

### Сборка из исходников

```bash
cd minecraft
./gradlew build          # Windows: gradlew.bat build
```

Готовые файлы: `lwl-skins/build/libs/lwl-skins-1.0.0.jar` и `lwl-auth/build/libs/lwl-auth-1.0.0.jar`.
Для сборки нужна Java 25 (например, Temurin 25).

## LWL Skins

### Команды

| Команда | Что делает |
|---------|-----------|
| `/skin` | Справка и текущий скин |
| `/skin set <ник>` | Скин любого лицензионного игрока, например `/skin set Notch` |
| `/skin url <ссылка>` | Скин из PNG по прямой ссылке (64×64) |
| `/skin url <ссылка> slim` | То же с тонкими руками (как у Алекс) |
| `/skin update` | Перекачать скин, если он поменялся |
| `/skin clear` | Вернуть скин по умолчанию |
| `/skin of <игрок> set\|url\|update\|clear …` | То же для другого игрока (OP 2+). Работает, даже если игрок не в сети |
| `/skin reload` | Перечитать настройки (OP 2+) |

Ссылка должна вести прямо на картинку `.png` и открываться без входа на сайт. Подойдут,
например, ссылки «Download» с NameMC, из Discord или с GitHub (`raw.githubusercontent.com`).

### Как это работает

Клиент Minecraft рисует только скины, подписанные Mojang. Поэтому:

- **по нику** мод берёт готовый подписанный скин у Mojang;
- **по ссылке** картинку загружает сервис [MineSkin](https://mineskin.org): он возвращает
  подписанный скин.

Без ключа MineSkin делает около 10 скинов в минуту. Для 20 игроков этого хватает.
Если не хватит, получите бесплатный ключ на mineskin.org и впишите его в `mineskinApiKey`.

Если игрок не выбирал скин, а его ник совпадает с лицензионным, ставится скин этой
лицензии (как в SkinsRestorer). Это отключается настройкой `skinFromNickname`.

### Настройки `config/lwl-skins.json`

| Поле | По умолчанию | Смысл |
|------|--------------|-------|
| `skinFromNickname` | `true` | Скин лицензии с таким же ником, если свой не выбран |
| `loginWaitMillis` | `3000` | Сколько ждать скин при входе; не успел — догрузится сам |
| `nicknameCacheHours` | `24` | Сколько помнить скины лицензий |
| `commandCooldownSeconds` | `30` | Пауза между сменами скина для обычных игроков |
| `allowPlayersToChangeSkin` | `true` | `false` — скины меняет только администрация |
| `mineskinApiKey` | `""` | Ключ MineSkin (необязательно) |
| `requestTimeoutSeconds` | `15` | Тайм-аут запросов к Mojang/MineSkin |

Выбранные скины хранятся в `config/lwl-skins/players.json`.

## LWL Auth

### Как игрок входит

- **С лицензией.** Если ник принадлежит лицензионному аккаунту, сервер проверяет игрока
  через Mojang, как в `online-mode=true`. Пароль не нужен. Зайти с пиратки под таким ником
  нельзя: клиент покажет «Invalid session».
- **Без лицензии.** При первом входе игрок придумывает пароль: `/register <пароль> <пароль>`.
  Дальше при каждом входе вводит `/login <пароль>` (или коротко `/l <пароль>`).
  Пока игрок не вошёл, он стоит на месте, его нельзя убить, чат и остальные команды
  не работают, права OP не действуют. На вход даётся 60 секунд.

Если игрок перезашёл с того же IP в течение 10 минут, пароль повторно не спрашивается.

### Безопасность

- Пароли хранятся только как хеш PBKDF2-SHA256 (600 000 итераций, соль). Восстановить
  пароль из файла нельзя.
- Соединение шифруется и у игроков без лицензии, поэтому пароль не передаётся открытым текстом.
  Проверено перехватом трафика.
- После 5 неверных паролей подряд — кик, и с этого IP минуту нельзя войти.
- Если ник уже защищён паролем, его не отберёт человек, который позже купит лицензию
  с таким же ником.
- Нельзя «выбить» с сервера игрока, который уже вошёл: второе подключение с тем же ником
  отклоняется.
- UUID у всех офлайновый (`keepOfflineUuid`), поэтому инвентари и приваты не теряются,
  если игрок перешёл с пиратки на лицензию.

### Команды

| Команда | Кто | Что делает |
|---------|-----|-----------|
| `/register <пароль> <пароль>` | игрок | Первый вход: придумать пароль (минимум 6 символов, без пробелов) |
| `/login <пароль>`, `/l <пароль>` | игрок | Войти |
| `/changepassword <старый> <новый>` | игрок | Сменить пароль |
| `/auth info <ник>` | OP 3+ | Как входит игрок, когда был последний вход |
| `/auth resetpassword <ник>` | OP 3+ | Сбросить забытый пароль: игрок придумает новый через `/register` |
| `/auth cracked <ник>` | OP 3+ | Пускать по паролю, даже если такой ник есть у лицензии (ник совпал с чужой лицензией) |
| `/auth premium <ник>` | OP 3+ | Только лицензия, без пароля |
| `/auth auto <ник>` | OP 3+ | Снова определять автоматически |
| `/auth unregister <ник>` | OP 3+ | Удалить аккаунт |
| `/auth reload` | OP 3+ | Перечитать настройки |

**Частый случай:** у игрока без лицензии ник совпал с чьим-то лицензионным, и его не пускает
(«Invalid session»). Решение — `/auth cracked <ник>` или сменить ник.

### Настройки `config/lwl-auth.json`

| Поле | По умолчанию | Смысл |
|------|--------------|-------|
| `premiumAutoLogin` | `true` | Лицензия входит без пароля |
| `keepOfflineUuid` | `true` | Один и тот же UUID для лицензии и пиратки |
| `encryptOfflineConnections` | `true` | Шифровать соединение и без лицензии |
| `loginTimeoutSeconds` | `60` | Время на `/login` / `/register` |
| `maxLoginAttempts` | `5` | Неверных паролей до кика |
| `lockoutSeconds` | `60` | Пауза для IP после кика за пароли |
| `sessionMinutes` | `10` | Перезаход с того же IP без пароля; `0` — спрашивать всегда |
| `minPasswordLength` | `6` | Минимальная длина пароля |
| `mojangTimeoutSeconds` | `5` | Сколько ждать ответ Mojang при проверке ника |
| `premiumCacheHours` | `24` | Сколько помнить, лицензионный ли ник |

Аккаунты хранятся в `config/lwl-auth/accounts.json`, рядом лежит резервная копия `.bak`.
Держите этот файл в бэкапах сервера и никому не отправляйте.

Если Mojang недоступен, а ник ещё ни разу не заходил, такой игрок входит по паролю.
Исправить это можно командой `/auth premium <ник>`.

## Как проверялось

Моды проверены на настоящем сервере Fabric 26.3 (`online-mode=false`) с настоящими клиентами 26.3:

- скин по нику и по ссылке (включая slim) виден и самому игроку (F5), и другим игрокам,
  без перезахода; `/skin clear` возвращает скин по умолчанию; кулдаун работает;
- регистрация и вход; отказ на простой пароль; сессия при перезаходе;
  кик по таймауту и после неверных паролей;
- до входа: заморозка, блокировка чата и команд, включая команды OP;
- пиратский клиент под лицензионным ником не пускается, `/auth cracked` это разрешает;
- пароль в трафике не виден (с выключенным шифрованием — виден).

Вход с настоящей лицензии не проверялся (для этого нужен купленный аккаунт). Эта часть
использует стандартную проверку сервера Minecraft через Mojang — ту же, что `online-mode=true`.
